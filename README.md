# SwapRoom

Static one-page crypto swap hub (ChangeNOW, SwapSpace, StealthEX widgets).

## Deploy
1. Push this folder to a GitHub repo (index.html must be at the root).
2. Vercel → Add New Project → import repo → Framework: **Other** → Deploy.

Deep links: `/#changenow`, `/#swapspace`, `/#stealthex` open that desk directly.
